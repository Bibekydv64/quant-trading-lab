# quant-trading-lab




A hands-on quantitative trading and Python programming practice repository.

This repository documents my journey from Python fundamentals to advanced quantitative trading systems through daily coding exercises, price action analysis, market structure, risk management, technical indicators, trading strategies, and backtesting.

**Main Topics:**
- Python programming and logic building
- Financial market and price analysis
- OHLCV and candlestick analysis
- Market structure and price action
- Risk management and position sizing
- Technical indicators
- Algorithmic trading strategies
- Strategy backtesting and performance evaluation

**Goal:** Develop strong programming, mathematical, and analytical skills to build systematic and data-driven trading systems.
